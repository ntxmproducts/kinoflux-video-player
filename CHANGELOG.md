## [1.2.1] - 2026-11-10

Current release of KinoFlux Player for Windows x64 and macOS Apple Silicon.

Downloads: [Windows installer](https://github.com/ntxmproducts/kinoflux-video-player/releases/download/v1.2.1/Kinoflux-Player-Setup-1.2.1-x64.exe) | [macOS installer (.pkg)](https://github.com/ntxmproducts/kinoflux-video-player/releases/download/v1.2.1/Kinoflux-Player-1.2.1-macos-arm64.pkg) | [Microsoft Store](https://apps.microsoft.com/detail/9PJC13FSD9FJ) | [release page](https://github.com/ntxmproducts/kinoflux-video-player/releases/tag/v1.2.1)

### Platforms
- **Windows 10/11 (64-bit)** installer: `Kinoflux-Player-Setup-1.2.1-x64.exe` (38,461,626 bytes). SHA-256 `32a7848afae8cfee02e9d61d6f5a20d7b65a7d0e841a11434226abc61e196613`.
- **macOS Apple Silicon** installer: `Kinoflux-Player-1.2.1-macos-arm64.pkg` (34,322,885 bytes). SHA-256 `c75d905f2229e34096300a3a92ede49a07c3759619e10743dbf46257a05424cd`.
- Also listed on the Microsoft Store as [KinoFlux Player](https://apps.microsoft.com/detail/9PJC13FSD9FJ) (product ID `9PJC13FSD9FJ`).
- **macOS packaging note:** 1.2.1 ships a **`.pkg` only** (no `.dmg`). The installer places the app in Applications and registers Finder Open With.

### Highlights
- **Music player** with its own audio engine: folder queue, shuffle, repeat, speed, pitch, and bass/mid/treble mixer
- **Refreshed UI** for home, player chrome, and the control bar
- Offline local video and music player with a dark minimal UI
- Home and library views for files on disk
- Playback with speed controls and picture/audio adjust
- Privacy-focused: no account required for playback, no telemetry for watching local files
- Hardware-accelerated engine for smooth 4K on supported hardware
- Common formats including MKV, MP4, AVI, MOV, WebM, and common audio types

### Fixed
- Floating control panel stayed visible after the main window was minimized; it now hides and returns with the Player page

### Notes
- Free proprietary software from ntxm. Not open source.
- Product page: https://www.ntxm.org/products/kinoflux/videoplayer/
